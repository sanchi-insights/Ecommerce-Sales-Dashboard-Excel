I developed an interactive Excel dashboard analyzing e-commerce sales performance. This process involved several stages, including data processing, data cleaning and data visualization using KPIs, Pivot Tables, Pivot Charts, and Slicers.

# 📊 E-commerce Sales Dashboard (Excel)

## 📌 Overview

Interactive Microsoft Excel dashboard developed to analyze e-commerce sales data using Pivot Tables, Pivot Charts, KPIs, and Slicers.

---

## 🎯 Objectives

* Analyze overall sales performance
* Track profit and order trends
* Compare category-wise performance
* Identify top-performing regions and states
* Build an interactive business dashboard

---

## 📂 Dataset

* Order ID
* Order Date
* Customer Details
* Product Category & Sub-Category
* Sales
* Profit
* Quantity
* Discount
* Region & State

---

## 📈 Dashboard Features

* KPI Cards

  * Total Sales
  * Total Profit
  * Total Orders
  * Total Quantity

* Interactive Slicers

* Monthly Sales Trend

* Category-wise Sales Analysis

* Regional Performance

* State-wise Sales Distribution

* Profit Analysis

---

## 🛠 Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* Excel Functions

---

## 📊 Key Insights

* Identify top-performing categories
* Compare regional sales performance
* Track monthly sales trends
* Analyze profitability across categories
* Monitor customer purchasing patterns
